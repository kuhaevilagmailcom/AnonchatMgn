# 🧲 Анонимный чат · Магнитогорск (AnonchatMgn)

Телеграм-бот анонимного общения для одного города: люди пишут друг другу, не зная ни ника, ни аватарки,
ни телефона — только текст (и немного мультимедиа). Внутри всё как в нормальном анонимном чате:
**🔎 поиск собеседника · ⏭ следующий · ⏹ остановить диалог · 🚩 жалоба**, плюс **📊 ранги по переписке**
и модерация с жалобами прямо в телеге.

Ветку `aiogram 2` (как в исходном примере) поднимать не стал — написал на **aiogram 3.31**, там
другой API (`Router`, `Dispatcher`, `executor` больше нет), зато есть нормальные инлайн-кнопки,
HTML-разметка, FSM и асинхронная база.

## Что умеет

| Возможность | Как выглядит |
|---|---|
| Меню | `🔎 Поиск собеседника` · `⏭ Следующий` · `⏹ Стоп` · `🚩 Жалоба` · `📊 Профиль` · `⚙️ Настройки` · `🏆 Топ` · `📜 Правила` · `❓ Помощь` — ровно 9 кнопок, по одному эмодзи на кнопку |
| 🧲 Собеседник найден | одним сообщением, **без кнопок**: `⏭ /next — следующий`, `⏹ /stop — остановить`, `🚩 /report — пожаловаться`. В диалоге ничто не мешает переписке |
| 🙋 Свой ник | `/nick Ким Вайнон` — ник придумывает сам участник, именно он виден другим в топе. Реальные имя и @username в публичных местах не показываются; если ник не задан — авто-ник вида `Аноним-1001` |
| 🏆 Топ | 🥇🥈🥉 + ники и число сообщений с рангом. Никаких настоящих имён |
| 📊 Ранги | считаются по сообщениям: 🔰 Старт → 🥉 **Бронза** (1 000) → 🥈 **Серебро** (15 000) → 🥇 **Золото** (100 000) → 💎 **VIP** (500 000), с полоской прогресса `▰▰▰▱▱▱▱▱` |
| ✨ Эмодзи из пака | бот подсматривает `custom_emoji_id` из сообщений участников, сохраняет в базу и начинает украшать паком **свои** тексты (`<tg-emoji>`); если Telegram запретит — молча откатывается на обычный Unicode |
| 📍 Подбор по району | три района МГН (🌇 Правобережный / 🌉 Левобережный / 🏭 Орджоникидзевский) + тумблер «только мой район»; фильтр работает, когда его включили оба |
| 💬 Анонимная пересылка | `send_copy` вместо `forward` — у сообщения нет шапки «Переслано от», так что личность не утекает |
| 🤐 Без лишних слов | бот **не пишет** «сообщение доставлено анонимно» и прочее в том же духе: человек и так понял, куда пришёл |
| 🛡 Кто что видит | бот не сообщает, с кем ты общаешься; в карточке жалобы нарушитель не узнаёт, кто на него нажал |
| 🚩 Жалобы | причина → комментарий → карточка админу с кнопками `🔇 Мут` `⛔ Бан` `👤 Профиль` `✅ Закрыть`; 3 жалобы за сутки → авто-мут на час и расцепка пары |
| 🔎 Очередь | позиция в очереди, пересборка подборов при смене района, повторная попытка, если собеседник заблокировал бота |
| 📈 Админ | `/stats`, `/queue`, `/reports`, `/ban`, `/unban`, `/mute`, `/find`, `/bc` (рассылка по активным за 7 дней) |
| 🧹 Забвение | `/forget` стирает профиль, опыт, ник, диалоги и жалобы полностью |
| 🐢 Анти-флуд | троттлинг на мидлваре, лимит длины сообщения, откат XP за недоставленные сообщения |

Стиль интерфейса: короткий текст, один эмодзи как маркер раздела, команды в `<code>`.
Ссылка на эмодзи-пак живет в `/help` — в главном меню её больше нет, чтобы не мозолить глаза.

## Структура

```
AnonchatMgn/
├── main.py                # точка входа: бот, диспетчер, мидлвари, команды, janitor
├── run.py                 # алиас: `python run.py` работает так же (историческое имя)
├── dev.py                 # старт одной командой: сам создаёт .venv и ставит зависимости
├── requirements.txt
├── Procfile               # `worker: python main.py` — для panel-хостингов с buildpack
├── .env.example
├── Dockerfile
└── anonchat/
    ├── config.py          # BOT_TOKEN / ADMIN_IDS / лимиты из env или .env
    ├── db.py              # aiosqlite: users, matches, reports, kv (+ миграции схемы)
    ├── levels.py          # таблица уровней и званий
    ├── matching.py        # очередь + подбор пар (in-memory)
    ├── nick.py            # правила ника: валидация, авто-ник, отображение
    ├── pack.py            # эмодзи городского пака в текстах бота
    ├── commands.py        # меню команд Bot API (общее + модераторское)
    ├── keyboards.py       # инлайн-кнопки
    ├── texts.py           # все тексты
    ├── actions.py         # connect/next/stop/профиль/ник/оценки — общая логика
    ├── middlewares.py     # DataContext (БД + ctx + пак) и Throttling
    └── handlers/
        ├── menu.py        # /start, /help, кнопки act:*, оценки rate:*
        ├── settings.py    # ник, район, «только свой район», пол, описание, /forget
        ├── reports.py     # /report (кнопка 🚩) и /feedback
        ├── chat.py        # catch-all: пересылка сообщений собеседнику + сбор id эмодзи
        └── admin.py       # модерация
```

## Быстрый старт

```bash
git clone https://github.com/kuhaevilagmailcom/AnonchatMgn.git
cd AnonchatMgn

python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt

cp .env.example .env       # впиши токен от @BotFather и свой Telegram ID
python main.py             # есть и алиас: python run.py
```

Как узнать свой ID для `ADMIN_IDS`: напиши [@userinfobot](https://t.me/userinfobot) — он покажет число.

Проверить, что ничего не сломано, можно без Telegram:

```bash
python -m tests.core    # уровни, матчмейкер, база
python -m tests.flow    # весь сценарий бота на фейковой Bot API-сессии
```

`tests/flow.py` прогоняет ~70 проверок: `/start` с кнопками и авто-ником, очередь, подбор пары,
пересылку, `unknown command` (не утекает собеседнику), `/stop` + опыт, оценку `👍`, смену района,
свой ник и анонимность топа, подглядывание `custom_emoji_id` и `<tg-emoji>` в текстах бота,
жалобу → карточку админу → мут → расцепку пары, «Следующий», доступ к `/stats`, `/forget`,
рассылку и `/mute` по «сырому» id.

## Настройка под свой город

Всё брендовое живёт в двух местах:

* `.env` — `CITY_NAME`, `CITY_SHORT`, `EMOJI_PACK_URL`, `AUTO_MUTE_REPORTS`, `AUTO_MUTE_MINUTES`, `DB_PATH`;
* `anonchat/texts.py` + `anonchat/levels.py` — тексты и названия уровней;
* `anonchat/handlers/settings.py::DISTRICTS` — районы (для МГН их три).

Хочешь чат для Челябинска — меняешь три строки в `DISTRICTS` и `CITY_NAME` в `.env`.

## Что хранится в базе

* `users` — id, имя/юзернейм (только для админ-карточек), `nickname` + `nick_key` (уникальный ник без
  учёта регистра — `COLLATE NOCASE` в SQLite кириллицу не понимает, поэтому ключ считаем в Python),
  xp, счётчики, район, пол, «о себе», бан/мут;
* `matches` — кто с кем, сколько сообщений с каждой стороны, кто завершил, оценки;
* `reports` — жалобы со статусом и модератором;
* `kv` — мелочи вроде подсмотренных `custom_emoji_id` городского пака (переживают рестарт).

Схема догоняется на лету: если база лежит со времён более старой версии, `Database.start()`
добавит недостающие колонки через `ALTER TABLE` и ничего не потеряет.

Очередь поиска и активные пары держатся в памяти процесса: после рестарта люди просто жмут
`🔎 Поиск собеседника` ещё раз, а опыт, ники и статистика никуда не деваются.

## Деплой

### Хостинг-панель, которая клонирует GitHub (BotHost и подобные)

1. Репозиторий **публичный**, ветка `main` — проверь, что в настройках бота на хосте стоит
   `https://github.com/kuhaevilagmailcom/AnonchatMgn` и ветка `main` (без `.git` на конце тоже ок).
   Если сборка падала, когда репозиторий был ещё пустой, панель часто держит кэш «пустого» клона —
   помогает пересоздать бота/перезапустить сборку, а не тыкать в то же самое.
2. Токен в репозитории **нет** (`.env` в `.gitignore`, и правильно делает). Заведи переменные
   окружения в панели: `BOT_TOKEN`, `ADMIN_IDS`. Панели, которые называют переменную иначе, тоже
   понимаются: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_TOKEN`, `BOT_KEY`, `TOKEN`; плюс можно передать токен
   аргументом — `python main.py <токен>`.
3. Точка входа — `python main.py` (есть `Procfile` и `Dockerfile`, зависимости в `requirements.txt`).
4. Если у панели файловая система только для чтения, база автоматически уедет во временный каталог —
   бот стартанет, но статистику переживёт только до перезапуска. Для постоянных данных нужен volume
   или переменная `DB_PATH`, указывающая в записываемую папку.

### Docker

```bash
docker build -t anonchat-mgn .
docker run -d --name anonchat-mgn \
  -v $PWD/data:/app/data \
  --env-file .env \
  --restart unless-stopped \
  anonchat-mgn
```

или `docker compose up -d`. Для VPS-варианта без Docker — `systemd`-юнит с `python main.py` и
`Restart=always`.

## Идеи, что докрутить

* темы для разговора при старте диалога (генератор вопросов «с какой стороны Магнитки ты?»);
* `/gender`-фильтр подбора и «ищу девушку/парня» (сейчас пол только в профиле);
* медиа-проверка на 18+ (MediaPipe/классификатор) перед пересылкой фото;
* второй город и выбор «чат по городам» через `startapp`;
* вебхук-режим (`aiogram.webhook.aiohttp_server`) — если захочется хостить на 1000+ человек.
